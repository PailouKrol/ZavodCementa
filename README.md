# ZavodCementa
# 🏭 Управление цементным заводом

Windows Forms приложение для управления складом, доставками, клиентами и сотрудниками цементного завода с использованием SQLite.

## 📋 Функционал

| Вкладка | Описание |
|---------|----------|
| **Склад** | Отображение материалов с прогресс-барами, возможность изменения количества (+/-) |
| **Доставка** | CRUD операции с таблицей доставок (отправитель, получатель, товар, объем, срок) |
| **Клиенты** | Управление клиентами (имя, телефон, адрес, UUID) |
| **Сотрудники** | Управление сотрудниками (должность, оклад, выполнение квоты) |

## 🛠️ Технологии

- **.NET 6.0 Windows Forms**
- **SQLite** — хранение данных
- **System.Data.SQLite.Core** — работа с БД
