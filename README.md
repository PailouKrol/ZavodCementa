# 🏭 Управление цементным заводом

Windows Forms приложение для управления складом, доставками, клиентами, сотрудниками, поставщиками и оборудованием цементного завода с использованием SQLite.

## 📋 Функционал

| Вкладка | Таблица | Описание |
|---------|---------|----------|
| **Склад** | *(без БД)* | Отображение материалов с прогресс-барами, кнопками +/-, цветовой индикацией |
| **Доставка** | Deliveries | CRUD операции с таблицей доставок (отправитель, получатель, товар, объём, срок) |
| **Клиенты** | Clients | Управление клиентами (имя, телефон, адрес, UUID) |
| **Сотрудники** | Employees | Управление сотрудниками (должность, оклад, выполнение квоты) |
| **Поставщики** | Suppliers | Управление поставщиками (наименование, контактное лицо, телефон, email, адрес, материал) |
| **Оборудование** | Equipment | Управление оборудованием (наименование, тип, статус, дата покупки, ответственный сотрудник) |

## 🛠️ Технологии

- **.NET 6.0 Windows Forms**
- **SQLite** — хранение данных
- **System.Data.SQLite.Core** — работа с БД
